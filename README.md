# Jomash-the-Vegetarian-Horror-2026
Jomash the Vegetarian - моя трёхмерная игра в стиле PS1 horror. Она короткая - на 10-20 минут. У неё есть две концовки.

Игра повествует о девушке, которая ночевала с друзьями в 2014 году. Ноябрь. Все уснули. Однако она не сдержала своего желания посмотреть,
что-же находится на диске, который нашли недавно её друзья. Она просыпается и запускает игру.
Но к чему-же приведёт такое любопытство?
